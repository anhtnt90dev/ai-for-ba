# Glossary

| Term | Ý nghĩa trong công việc BA |
| --- | --- |
| LLM | Language model dự đoán và biến đổi văn bản dựa trên context. |
| Hallucination | Câu trả lời tự tin nhưng không được source hoặc thực tế hỗ trợ. |
| RAG | Retrieval-Augmented Generation: truy xuất tài liệu nguồn trước khi sinh câu trả lời. |
| Acceptance criteria | Điều kiện giúp requirement test được và đủ để release. |
| Traceability | Mapping business goal với requirement, test, evidence và decision. |
| Human-in-the-loop | Workflow trong đó con người review, sửa hoặc approve output của AI. |
| Confidence threshold | Ngưỡng chất lượng quyết định output AI được đi tiếp hay phải fallback. |
| Evaluation | Cách đo có hệ thống chất lượng output AI so với behavior mong muốn. |
