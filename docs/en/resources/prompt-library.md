# Prompt Library

## Discovery prompt

```text
Act as a senior BA. Create a discovery plan with stakeholders, business goals, assumptions, interview questions, risks, and decisions needed.
```

## Requirement review prompt

```text
Review these requirements for ambiguity, conflict, missing actors, missing data, NFR gaps, edge cases, and testability. Return severity, evidence, and clarification questions.
```

## AI feature prompt

```text
Specify this AI-enabled feature with user goal, data sources, model task, output contract, confidence threshold, human review, fallback, monitoring, and evaluation metrics.
```
